# El término constante del problema de las n reinas

Dilan Steven Mejia

DOI: [10.5281/zenodo.24248206](https://doi.org/10.5281/zenodo.24248206)

Este repositorio reúne el artículo y los programas de verificación exacta.

| Carpeta | Contenido |
|---|---|
| `es/articulo/` | El artículo en español: fuentes LaTeX, que se compilan con XeLaTeX, y el PDF |
| `es/verificacion/` | Los programas que comprueban con aritmética exacta las identidades, los ejemplos y las figuras del artículo, y su correspondencia con el texto |
| `en/` | La versión en inglés de las dos carpetas: `paper/` y `verification/` |
